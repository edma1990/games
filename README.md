# سامانه نوبت‌دهی مرکز تخصصی طب کار کوثر

نسخه آزمایشی سامانه ثبت نوبت، کنترل ظرفیت، دریافت تصویر و پنل کارشناسی.

## امکانات نسخه ۰.۱

- تقویم ۳۰ روزه با تعطیلی جمعه
- نوبت‌های ۲۰ دقیقه‌ای از ۷:۲۰
- شنبه تا چهارشنبه تا ۱۳:۴۰ و پنج‌شنبه تا ۱۲:۴۰
- اعتبارسنجی کد ملی و شماره همراه فارسی/انگلیسی
- جلوگیری از نوبت فعال تکراری و رزرو هم‌زمان یک ساعت
- بررسی اولیه ابعاد، نور و تاری تصویر
- رمزگذاری کد ملی و تلفن در بانک اطلاعاتی
- لغو نوبت تا ۲۴ ساعت قبل
- پنل کارشناسی و خروجی CSV قابل بازکردن در Excel
- رابط فارسی و راست‌چین برای بررسی جریان کار پیش از اتصال به بله

> تشخیص وجود دقیقاً یک چهره و اتصال Webhook بله در مرحله بعد اضافه می‌شوند. بررسی فعلی تصویر فقط کنترل اولیه کیفیت است.

## اجرای محلی

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

سامانه: `http://localhost:8000`

پنل: `http://localhost:8000/admin`

اطلاعات پیش‌فرض پنل در محیط توسعه:

- نام کاربری: `admin`
- رمز: `change-this-before-production`

این رمز فقط برای اجرای محلی است و برنامه در محیط production با این رمز اجرا نمی‌شود.

## آزمایش‌ها

```bash
.venv/bin/pytest -q
```

## تنظیمات محرمانه

فایل `.env.example` را به `.env` کپی کنید. فایل `.env` در Git ثبت نمی‌شود. توکن بازوی بله و کلیدهای واقعی را هرگز در کد، گفت‌وگو یا GitHub قرار ندهید.

برای تولید کلید رمزگذاری:

```bash
.venv/bin/python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
